# Качество вина

Приложение на Streamlit для отбора хороших вин по результатам лабораторного анализа. Позволяет получать отдельные и пакетные прогнозы, менять порог классификации и просматривать метрики модели.

Модель решает задачу бинарной классификации:

- Класс 1 - вино с экспертной оценкой не ниже 7;
- Класс 0 - вино с оценкой ниже 7.

## Возможности

| Вкладка | Что можно сделать |
|---|---|
| Одно вино | Ввести 12 признаков и получить вероятность хорошего вина и решение по текущему порогу |
| Выбор порога | Изменить порог и посмотреть, как меняются матрица ошибок, precision, recall, F1 и рабочие точки на roc- и pr-кривых |
| Пакетное предсказание | Загрузить CSV, получить прогноз для каждой строки и скачать результат |
| Коэффициенты | Посмотреть веса модели после стандартизации признаков и их интерпретацию |

Порог общий для всех вкладок. Пример входного CSV можно скачать во вкладке пакетного предсказания.

## Модель

Используется сохраненный пайплайн `StandardScaler` и `LogisticRegression` без весов классов. Приложение загружает готовую модель из `model.joblib`.

Начальный порог **0.269091** выбран по максимальному F1 на валидационной выборке и хранится в `config.json`. Если вероятность класса 1 не ниже текущего порога, вино попадает в рекомендации. Метрики и графики рассчитываются по тестовой выборке из `test.csv`.

## Локальный запуск

Для запуска используйте **Python 3.11** и версии библиотек из `requirements.txt`. Модель сохранена с `scikit-learn==1.2.2`.

### Windows

Откройте терминал в папке `wine_app` и выполните:

```
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

### macOS и Linux

В терминале из папки `wine_app`:

```
python3.11 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m streamlit run app.py
```

Откройте локальный адрес, который появится в терминале. Для остановки сервера нажмите `Ctrl+C`.

## Формат входного CSV

Файл для пакетного предсказания должен содержать 12 признаков с такими названиями:

```
fixed_acidity,volatile_acidity,citric_acid,residual_sugar,chlorides,free_sulfur_dioxide,total_sulfur_dioxide,density,pH,sulphates,alcohol,is_red
```

- Кодировка - UTF-8, разделитель - запятая, десятичный разделитель - точка;
- Значения признаков должны быть числами без пропусков и бесконечности;
- is_red=1 означает красное вино, is_red=0 - белое;
- Порядок столбцов может быть любым: приложение приведет его к порядку признаков модели;
- Столбец target для получения прогноза не требуется;
- Дополнительные столбцы сохраняются в результате, но не используются моделью.

К исходной таблице добавляются два столбца:

| Столбец | Содержимое |
|---|---|
| probability | Вероятность класса 1, предсказанная моделью |
| prediction | Класс 0 или 1 при текущем пороге |

Если файл пустой, отсутствует нужный признак или встречаются некорректные значения, приложение показывает сообщение об ошибке.

## Кеширование

- `st.cache_resource` сохраняет модель как общий ресурс. При изменении виджетов используется тот же объект без повторного вызова `joblib.load`.
- `st.cache_data` сохраняет таблицы, настройки и массивы вероятностей. Эти результаты возвращаются как копии данных.
- Вероятности для тестовой и загруженной таблиц кешируются. При изменении порога пересчитываются метки, метрики и рабочие точки, без повторного `predict_proba` для той же таблицы.

Без кеширования `joblib.load` читал бы модель с диска при каждом изменении виджета. Для модели используется `st.cache_resource`, чтобы переиспользовать объект; `st.cache_data` сериализовал бы его и возвращал копии.

После замены `model.joblib`, `config.json` или `test.csv` очистите кеш Streamlit или перезапустите сервер.
